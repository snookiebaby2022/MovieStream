Install

Watch on phone, tablet & TV

Use the same FlixNova account everywhere. Android & Fire Stick get a native app shell. iPhone/iPad install the site as a Home Screen app (Apple’s supported path without the App Store).

Android phone / tablet

Install the FlixNova APK (sideload). It opens the live site in a full-screen app.

  1. 1. Download the latest APK from your admin / GitHub Releases (or build with Android Studio).
  2. 2. Allow “Install unknown apps” for your browser/Files.
  3. 3. Open FlixNova → Sign in → Watch.
Get Android APK

Fire Stick / Fire TV

Same Android APK, installed via Downloader or ADB. Optimized for leanback / remote.

  1. 1. On Fire Stick: Settings → My Fire TV → Developer Options → Apps from Unknown Sources ON.
  2. 2. Install the Downloader app from Amazon Store.
  3. 3. Enter your APK download URL → Install → Launch FlixNova.
Fire TV sideload help

iPhone / iPad

Apple doesn’t allow easy sideload of streaming wrappers. Install FlixNova as a Home Screen web app — looks and feels like a native app.

  1. 1. Open Safari (required) → go to FlixNova.
  2. 2. Tap the Share button.
  3. 3. Tap Add to Home Screen → Add.
  4. 4. Open the FlixNova icon → Sign in & watch fullscreen.

Developers: native project lives in apps/flixnova (Capacitor). Build Android/Fire TV with Android Studio; optional iOS target needs a Mac + Xcode + Apple Developer account. The apps load your live site at snookiebaby.xyz:8443 so updates ship with the website.
