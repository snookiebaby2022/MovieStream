Install

Watch on phone, tablet & TV

Same FlixNova account everywhere. Android & Fire Stick use the APK. iPhone/iPad install via Safari Home Screen.

Android phone / tablet

Download the FlixNova APK and install it (sideload). It opens the live site fullscreen.

  1. 1. Tap Download APK below.
  2. 2. Allow “Install unknown apps” for your browser/Files.
  3. 3. Open FlixNova → Sign Up / Log In → Watch.
Download Android APK

Fire Stick / Fire TV

Install the same APK with the Downloader app (easiest), or paste the APK URL.

Code for Downloader App
3777174
  1. 1. Settings → My Fire TV → Developer Options → Apps from Unknown Sources ON.
  2. 2. Install Downloader from the Amazon store.
  3. 3. Open Downloader → enter code 3777174 → Go → Download → Install.
  4. 4. Open FlixNova → Sign Up / Log In → Watch.

iPhone / iPad

Use Safari (required): Share → Add to Home Screen.

  1. 1. Open FlixNova in Safari.
  2. 2. Tap Share.
  3. 3. Tap Add to Home Screen → Add.
  4. 4. Open the icon → Sign in & watch fullscreen.
Open FlixNova

Fire Stick tip: in Downloader, type code 3777174 — faster than pasting a long URL. Reinstall if embeds show 403 Forbidden.
