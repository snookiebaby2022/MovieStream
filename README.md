## Installation

```bash
# Clone the repository
git clone git@github.com:snookiebaby2022/MovieStream.git

# Navigate to project
cd MovieStream

# Install dependencies
npm install

# Set up environment
cp .env.example .env 2>/dev/null || echo "Create .env file with required variables"
```

## Available Scripts

```bash
# Development
npm run dev

# Build
npm run build

# Test
npm test

# Start production
npm start
```
